# nodecheck

Проверка сервера под VPN-ноду: перед покупкой и установкой, при жалобах «тормозит», если забился диск.
Самостоятельный скрипт, ни к чему не привязан. Без флагов **ничего не меняет** — только показывает.

```bash
bash <(curl -sL https://raw.githubusercontent.com/ShuntVPN/nodecheck/main/nodecheck.sh)
```

Поставить командой `nodecheck` (дальше всегда берёт свежую версию):

```bash
bash <(curl -sL https://raw.githubusercontent.com/ShuntVPN/nodecheck/main/nodecheck.sh) --install
```

| Флаг | Что делает |
|---|---|
| *(без флагов)* | полная проверка |
| `--quick` | без замера скорости |
| `--fix` | проверка + исправить найденное (спросит, сделает бэкап) |
| `--fix --yes` | то же без вопросов (Docker всё равно не перезапускает) |
| `--restore` | вернуть файлы из последнего бэкапа |

## Что проверяет

1. **Система** — KVM или контейнер (OpenVZ/LXC), AES-NI, ядро для BBR, синхронизация времени.
2. **Процессор** — стил (≤3% хорошо, до 10% терпимо), нагрузка, процессы-паразиты.
3. **Память** — занятость, падения из-за нехватки памяти (OOM) за неделю.
4. **Диск** — занятость и что раздулось: журнал systemd, логи nginx, `btmp`, логи Xray и контейнеров, кэш apt.
5. **Сеть** — MTU, IPv4/IPv6, DNS, пинг до России (≤160 мс хорошо, до 400 терпимо), исходящий 25-й порт, скорость.
6. **IP** — гео, провайдер, помечен ли как прокси.
7. **Ядро** — BBR и fq, буферы TCP, разгон после паузы, MTU probing, таблица соединений, очереди, лимит файлов Docker.
8. **Docker** — лимиты логов, состояние remnanode.

Итог: **В ПОРЯДКЕ** (код 0), **РАБОЧИЙ С ОГОВОРКАМИ** (1), **НЕ ГОТОВ** (2).

## Что меняет `--fix`

Только то, что нашла проверка. Копии старых файлов — в `/root/nodecheck-backup-ДАТА`.

- `/etc/sysctl.d/99-nodecheck.conf` — BBR+fq, буферы 16 МБ, без сброса разгона, MTU probing, таблица соединений 262144, очереди. Действует сразу.
- `/etc/systemd/journald.conf` — журнал не больше 200 МБ; `/var/log/btmp` обнуляется.
- `/etc/docker/daemon.json` — лимит логов контейнеров (только если файла ещё нет).
- `docker.service.d/limits.conf` — лимит открытых файлов 1048576.
- Docker перезапускается только после отдельного вопроса (клиенты переподключатся за 10–20 секунд).
